绑定准入：[01-当前版本测试准入-2026-08-07.md](01-当前版本测试准入-2026-08-07.md)

## 1. 使用方式

本文件描述当前本地工作树的黑盒测试族。每个用例在正式执行时必须绑定候选包 SHA-256、环境、测试存档和证据。除明确标为 `REVIEW-NUM/UX` 的用例外，失败默认进入 `FAIL-FIX`。

优先级：P0 为每个候选包必跑；P1 为当前变更及主循环全回归；P2 为全面测试矩阵。`D` 表示破坏性，仅能在一次性账号/目录执行。

### 1.1 玩家画像

| 代号 | 行为 |
| --- | --- |
| S 顺从 | 阅读并按引导完成，不主动跳过 |
| I 急躁 | 双击/连点、跳动画、快速进退面板、转场中输入 |
| E 探索 | 逆序玩法、错误对象、离开目标、切语言和窗口 |
| D 破坏 | 断网、杀进程、锁文件、改时间、制造冲突 |
| L 目标语言 | 不看中文/英文，只凭目标语言完成任务 |

### 1.2 合法测试存档

执行前通过正常玩家操作分别建立并只读归档：`NEW` 全新档、`ONB-n` 引导阶段、`P1` 单宠、`P2MAX` 两只同阶满级、`HATCH` 待收蛋、`FUSE-PENDING` 待融合结果、`RICH` 丰富图鉴/皮肤、`FACTORY-MID` 工厂中局、`CLOUD-A/B` 双机分叉。不得直接编辑字段来构造通过证据。
